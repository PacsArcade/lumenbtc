# pacBOT Attendant

The artist's first hire: a texted-by-phone OpenClaw agent on Plow that answers
"how do I pay you in bitcoin", walks customers to the artist's own checkout,
tells fans about the next meetup, and helps the organizer write letters to the
community. It never touches keys and never holds money.

This repo is content only: a persona, skills, and a Dockerfile that builds on
Plow's OpenClaw base image. Built for the AI Worth Using × AgentCribs
OpenClaw 2.0 Hackathon.

Status: scaffold. The build lane is T-423.
